Depth Token Merge Study

Can depth information help a vision-language model when the model merges image tokens? This page shows the methods with diagrams and the results with charts.

Models LLaVA-OneVision-7B, -0.5B Questions VQAv2 counting 1,000 · GQA 12,578 Tokens 729 per image; merge 156 to 650

Each cell compares a Depth method with ToSA on the same questions. ▲ means the Depth method is higher. ● means no clear difference. ▼ means ToSA is higher.

How token merge works

  • The vision encoder makes 729 tokens from one image.
  • In each layer, the merge step joins similar tokens. Thus, fewer tokens go to the language model.
  • Fewer tokens make the model faster. But the answer can become less accurate.

How each method selects tokens

MethodTokens that the method merges
No token mergeNo tokens. This is the reference.
ToMeTokens with similar features (official ToMe).
ToSATokens with similar features, depth and position. The depth weight increases in each layer (official ToSA).
Depth-onlyTokens in the same depth region with near depth and position. The method keeps the edge tokens.
Depth-RGBThe same rules as Depth-only. The method also uses feature similarity (weight 0.5).

All methods give the RGB image to the language model. The name "Depth-only" tells only how the method selects tokens.

Scores at each merge level

Show the values as a table
  • VQA accuracy: the official VQAv2 score. It compares the answer with 10 human answers.
  • RCA: for the 911 questions with a count of 1 or more, the mean of 1 − |prediction − answer| / answer.
  • Exact match: the first sentence of the answer is the same as the correct answer, after normalization.

Speed and compute

Fewer tokens mean fewer FLOPs. But the time also includes the work that selects the tokens. The full report is in docs/latency_and_compute.md.

Show the values as a table
  • FLOPs: the four methods have the same FLOPs (within 0.3%). At 650 merged, the FLOPs are 18% (7B) and 32% (0.5B) of No token merge.
  • 7B: ToMe is up to 1.78 times faster than No token merge. ToSA with the depth model is not faster.
  • 0.5B: no method is faster than No token merge. The language model is too small to fill the GPU.
  • Depth methods: Depth-only makes all 26 merge plans before the encoder (about 110 ms). Depth-RGB makes a new plan in each layer, so its time grows with the merge level. This work is not in the FLOPs.
